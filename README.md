# Words Memo

Learn English and German words (and languages you add) with Russian translations.

| Folder | What | Start |
| --- | --- | --- |
| [`mobile/`](mobile/) | React Native app (Android + iOS), offline-first | `cd mobile && npm install && npm start` |
| [`backend/`](backend/) | NestJS sync server, dictionaries, share codes | see [backend/README.md](backend/README.md) |
| [`web/`](web/) | Website (Vite + React) | see [web/README.md](web/README.md) |

Each folder is a separate project with its own `package.json`.
